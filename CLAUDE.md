# Skills policy

Before making any UI/frontend change (components, pages, styling, layout, color, typography), invoke these skills together, in this order:

1. `ui-ux-pro-max` — design intelligence (styles, palettes, type pairings, UX guidelines)
2. `frontend-design` — production-grade implementation quality
3. `web-design-guidelines` — Vercel's web design conventions
4. `caveman` — ultra-compressed response mode for the final summary

Use all four for every design/UI change, not just one. `caveman` applies to how the change is communicated back to the user, not to the implementation itself.
